# Агентская документация проекта

Этот каталог — единая точка входа для ИИ-агентов и разработчиков. Здесь хранится
контекст, который накапливается между сессиями, чтобы агенты не перечитывали кодовую
базу и не «жгли токены» на уже известные вещи.

## Оглавление

| Файл | Что внутри |
|------|-----------|
| `ROADMAP.md` | План развития: что сделано, что планируется, приоритеты |
| `HISTORY.md` | Хронология изменений: по коммитам и по сессиям |

Краткий справочник команд, окружения и «готов» — в корневом `AGENTS.md` (загружается
автоматически в каждую сессию).

## Правила ведения

1. **ROADMAP.md** — держи актуальным. Задачи появляются/закрываются — обновляй
   статус и дату.
2. **HISTORY.md** — дополняй в конце каждого крупного блока работы (коммит или
   сессия). Формат: дата, суть, какие файлы затронуты, статус.
3. Не выдумывай факты: только то, что реально сделано и проверено (тесты, git log,
   запуск команд).
4. Если правка меняет правила для агентов — обнови корневой `AGENTS.md`, а не
   только эти файлы.
